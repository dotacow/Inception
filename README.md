# Prerequisites and Instructions
 being a project about docker, you will need ***docker*** installed, as well as sudo privileges.

all interaction with the system is done through a makefile which wraps around the compose.


 to build and run the project:
```bash
make up
 ```

to stop the containers:
```bash
make down
```
for an extensive list of commands and instructions, please refer to the [developer documentation.](./DEV_DOC.m)
